# Discord-бот: выбор услуги и тикеты

Бот выкладывает в канал панель (как у Gotham Cashout): баннер, описание, кнопки «Инфо», «Оплата», «Кэшбэк», «Отзывы», кнопки услуг и «Быстрый заказ» / «Оптом». Клиент выбирает услугу, вводит количество и комментарий, и бот создаёт **приватный канал-тикет**, который видят только клиент и роль персонала. В тикете есть кнопки «Взять тикет» и «Закрыть».

Файлы:
- `bot.py` — сам бот
- `config.json` — все тексты, услуги, цены, способы оплаты, баннер, ID ролей и каналов
- `requirements.txt` — зависимости
- `.env.example` — пример файла с токеном

## 1. Создать бота в Discord

1. Открой https://discord.com/developers/applications → **New Application**, введи имя.
2. Слева **Bot** → **Reset Token** → скопируй токен (никому его не показывай).
3. Там же: если хочешь сохранять переписку тикетов в лог, включи **Message Content Intent**. Иначе ничего включать не надо.
4. Слева **OAuth2 → URL Generator**:
   - Scopes: `bot`, `applications.commands`
   - Bot Permissions: `Manage Channels`, `Manage Roles`, `View Channels`, `Send Messages`, `Attach Files`, `Read Message History`, `Embed Links`
   - Открой ссылку внизу и добавь бота на свой сервер.
5. Роль бота в настройках сервера должна стоять **выше** роли персонала.

## 2. Установка

Нужен Python 3.10+.

```bash
cd discord-ticket-bot
pip install -r requirements.txt
```

Создай файл `.env` рядом с `bot.py` (можно скопировать `.env.example`):

```
DISCORD_TOKEN=твой_токен
```

## 3. Настроить config.json

Включи в Discord **Настройки → Расширенные → Режим разработчика**, тогда по правому клику можно «Копировать ID».

| Поле | Что это |
|---|---|
| `guild_id` | ID сервера. С ним команда `/panel` появляется сразу. |
| `ticket_category_id` | ID категории для тикетов. Если `0`, бот сам создаст категорию «Тикеты». |
| `staff_role_id` | ID роли персонала: она видит все тикеты и может их брать и закрывать. |
| `log_channel_id` | Канал для логов (открыт/закрыт тикет). `0` — без логов. |
| `save_transcripts` | `true` — при закрытии в лог уходит .txt с перепиской (нужен Message Content Intent). |
| `max_open_tickets_per_user` | Сколько тикетов одновременно может быть у одного клиента. |
| `accent_color` | Цвет полоски слева у панели. |

**Услуги** — список `services`. Сейчас там заглушки (Telegram Stars, Premium, Steam, Другое), поменяй на свои:

```json
{
  "id": "tg_stars",
  "name": "Telegram Stars",
  "emoji": "⭐",
  "description": "Звёзды Telegram на твой аккаунт.",
  "price": "от 1.4 ₽ за звезду"
}
```

`id` — любое короткое слово латиницей, уникальное. Кнопки идут по 5 в ряд.

**Панель** — блок `panel`:
- `banner` — ссылка на картинку (`https://...`) или имя файла рядом с `bot.py` (например `banner.png`). Пусто — без баннера.
- `title`, `subtitle`, `services_title`, `footer` — тексты.
- `sections` — строки с кнопкой справа. Тип кнопки: `info` (показывает текст из `info_texts` по её `id`), `payments` (выбор способа оплаты), `link` (ссылка, например на отзывы FunPay).

**Способы оплаты** — `payment_methods`. Клиент один раз выбирает способ и вводит реквизиты, и они подставляются в каждый его тикет. Хранятся в `data/users.json`.

Discord разрешает максимум 40 элементов в одной панели, так что не добавляй десятки секций и услуг.

## 4. Запуск

```bash
python bot.py
```

В нужном канале напиши **`/panel`** (нужно право «Управлять сервером»). Бот отправит панель.

После правки `config.json` бота перезапускать не нужно: просто удали старую панель и снова вызови `/panel`. Кнопки старых панелей и тикетов продолжают работать и после перезапуска бота.

Чтобы бот работал постоянно, его нужно запускать на сервере/VPS (например через `screen`, `systemd` или хостинг для ботов), а не на своём компьютере.
